# Research Log (Canonical Memory)

This folder is the canonical memory for the project. Slack is for discussion; GitHub is for stabilized outputs.

## How to use
- If something is “true enough to build on,” it goes into `/research-log/`.
- If something is speculative, it stays in Slack until promoted here.
